1.1.0 - Armory & Storage Expansion
- Extend empty slot cleanup to Armouries and all shared channel storage buildings (Libraries, Pantries, Treasuries, Hoards).
- Equipment slots hide automatically when their stored count drops to zero and return when restocked.
- Open Armory menus automatically refresh when equipment availability changes.

- Hide troop-type slots when their stored count reaches zero, including stale entries in existing sessions.
- Restore slots automatically when troops are stored in that color channel again.
- Refresh open Guild House menus when availability changes.
- Preserve all eight color selectors, native input choices, output settings, troop data and save format.
